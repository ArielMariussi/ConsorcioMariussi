# 💼 Consórcio Mariussi

Gerenciador de cotas de consórcio. Cadastre suas cotas (**Administradora**, **Grupo** e **Cota**) e acompanhe **quanto você já investiu** e **quanto já teve de lucro** em cada uma.

---

## ✨ Funcionalidades

- 📋 **Cadastro de cotas**: registre a administradora, o grupo e o número da cota
- 💰 **Total investido**: soma de tudo o que já foi pago em cada cota
- 📈 **Lucro**: retorno obtido em relação ao valor investido
- 📊 **Visão geral**: resumo consolidado de todas as suas cotas
- 🔐 **Autenticação**: login com JWT + ASP.NET Identity

> **Regra de negócio:** cada consórcio possui sempre **uma única cota**.
